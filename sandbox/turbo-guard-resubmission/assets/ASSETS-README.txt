TURBO GUARD - PLUGIN ASSETS
=============================

For WordPress.org submission, you'll need these image assets:

REQUIRED:
---------
1. icon-128x128.png    (Plugin icon - shows in search results)
2. icon-256x256.png    (Plugin icon - retina version)

RECOMMENDED:
------------
3. banner-772x250.png  (Plugin header banner)
4. banner-1544x500.png (Plugin header banner - retina)

5. screenshot-1.png    (Dashboard view)
6. screenshot-2.png    (Scanner with results)
7. screenshot-3.png    (Bulk delete interface)
8. screenshot-4.png    (Firewall logs)
9. screenshot-5.png    (Settings page)

HOW TO CREATE:
--------------
Icons (128x128 & 256x256):
- Use a shield icon with "TG" text or turbo logo
- Blue (#2271b1) primary color
- Simple, recognizable design
- SVG → PNG export at exact dimensions

Banners (772x250 & 1544x500):
- "Turbo Guard Security" text
- Tagline: "Scan. Clean. Protect."
- Shield iconography
- Blue gradient background

Screenshots:
- Take actual screenshots from WordPress admin
- Minimum width: 772px
- Use Chrome with responsive mode for consistent sizing
- Annotate key features with arrows/highlights (optional)

TOOLS:
------
- Figma (free): https://figma.com
- Canva (free): https://canva.com
- GIMP (free): https://gimp.org
- Icons: https://heroicons.com (shield icon)

UPLOAD TO WORDPRESS.org:
------------------------
Assets go in the SVN `assets/` folder (NOT in plugin zip):
/assets/icon-128x128.png
/assets/icon-256x256.png
/assets/banner-772x250.png
/assets/banner-1544x500.png
/assets/screenshot-1.png
... etc

The plugin ZIP should NOT contain these files.

TEMPORARY SOLUTION:
-------------------
For initial submission, WordPress.org will use default placeholder icons.
You can add real assets later via SVN without releasing a new version.
